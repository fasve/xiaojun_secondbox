# 墨香书库 · 个人图书管理

一个无需安装、打开即用的个人图书管理页面。所有功能都封装在单个 HTML 文件中，界面偏纸质书桌风格，适合管理几十到几百本私人藏书。

> 直接双击 [`index.html`](./index.html) 即可使用，不需要 Node.js、数据库或网络连接。

---

## 功能一览

- **图书管理**：新增、编辑、删除图书，记录书名、作者、ISBN、分类、出版社、出版年份、单价、库存、存放位置和备注。
- **即时搜索**：按书名、作者、ISBN、分类、出版社、位置和备注进行多关键词搜索，空格分隔多个关键词。
- **分类筛选**：分类选项根据现有藏书自动生成；支持按“有库存 / 库存紧张 / 已缺货”筛选。
- **多种排序**：最近添加、按书名、库存从少到多、价格从高到低、出版年份从新到旧。
- **馆藏统计**：自动统计馆藏品种、馆藏册数、分类数量和库存预警数量。
- **库存状态**：`0` 册显示“缺货”，`1–2` 册显示“库存紧张”，`3` 册及以上显示“在库”。
- **本地持久化**：数据保存在浏览器 `localStorage` 中，关闭页面后仍会保留。
- **备份迁移**：支持导出/导入 JSON 备份，换浏览器或换电脑时可迁移数据。
- **多标签页同步**：在另一个标签页修改书架后，当前页会自动读取新数据。
- **响应式布局**：桌面端为表格视图，窄屏自动切换为卡片式列表。
- **键盘操作**：按 `/` 快速聚焦搜索框，按 `Esc` 关闭弹窗。

## 快速开始

1. 打开本项目文件夹。
2. 双击 [`index.html`](./index.html)，或将它拖入浏览器窗口。
3. 首次打开会载入 10 本示例图书，可以直接编辑，也可以全部删除后建立自己的书架。

不需要执行 `npm install`，也不需要启动本地服务器。页面没有引用任何外部 CDN、字体或图片资源，离线也能完整使用。

### 推荐浏览器

最新版本的 Chrome、Edge、Firefox、Safari。页面使用原生 `<dialog>`、CSS Grid 和 `localStorage`，过旧的浏览器可能无法正常显示弹窗。

## 使用说明

### 新增图书

点击右上角 **新增图书**，填写书名、作者和分类后保存。库存默认是 `1` 册。

### 编辑与删除

每行图书右侧有两个图标按钮：

- 铅笔图标：编辑图书信息。
- 垃圾桶图标：删除图书。删除前会再次确认，操作不可撤销。

### 搜索与筛选

- 在搜索框输入任意关键词，列表会即时更新。
- 搜索支持多个关键词，例如 `余华 作家` 或 `科幻 刘慈欣`。
- 分类下拉框会随藏书变化自动更新。
- “库存紧张”指库存为 `1–2` 册的图书；“已缺货”指库存为 `0` 册。
- 点击 **重置筛选** 可清空搜索词、分类和库存筛选。

### 导入与导出

- **导出**：生成 `moxiang-books-YYYYMMDD.json`，包含当前全部图书记录。
- **导入**：选择本应用导出的 JSON 文件后，会覆盖当前书架，导入前有确认提示。
- 导入也接受“图书记录数组”形式的纯 JSON 数组，但推荐使用导出文件，格式更完整。
- 导入时会自动跳过没有书名或作者的记录，并为重复的 `id` 重新生成标识。

> 建议定期导出一份备份。清除浏览器数据、使用无痕模式或更换设备都可能导致本地数据丢失。

### 键盘快捷键

| 按键 | 功能 |
| --- | --- |
| `/` | 在页面空白处按下，快速聚焦搜索框 |
| `Esc` | 关闭当前弹窗 |
| `Tab` / `Shift + Tab` | 在表单和按钮之间移动焦点 |

## 数据存储

数据保存在当前浏览器的 `localStorage` 中，键名为：

```text
moxiang-library-v1
```

需要注意：

- 数据与“浏览器 + 设备 + 页面来源”绑定，不会自动同步到云端或其他电脑。
- 无痕/隐私模式关闭后，数据通常会被清除。
- 清除浏览器站点数据、缓存或使用清理工具可能删除藏书。
- 直接双击本地文件打开时，部分浏览器会按文件来源隔离本地存储；部署到网站后，数据归属该网站域名，两者不共享。
- 多标签页修改通过浏览器的 `storage` 事件自动同步。

### 恢复示例数据

打开浏览器开发者工具，在控制台执行：

```js
localStorage.removeItem("moxiang-library-v1");
location.reload();
```

刷新后会重新生成 10 本示例图书。**这会清空当前书架，请先导出备份。**

## 数据格式

导出的 JSON 结构如下：

```json
{
  "app": "moxiang-library",
  "version": 1,
  "exportedAt": "2026-11-03T01:31:13.000Z",
  "books": [
    {
      "id": "9a5f6e20-4e4e-4f70-9a9f-51a1f6f27fb2",
      "title": "百年孤独",
      "author": "加西亚·马尔克斯",
      "isbn": "9787544253994",
      "category": "文学小说",
      "publisher": "南海出版公司",
      "year": 2011,
      "price": 39.5,
      "stock": 4,
      "location": "客厅书架 A-01",
      "notes": "范晔译本。",
      "createdAt": "2026-11-02T02:00:00.000Z",
      "updatedAt": "2026-11-02T02:00:00.000Z"
    }
  ]
}
```

字段说明：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 内部唯一标识，由页面自动生成 |
| `title` | string | 书名，必填 |
| `author` | string | 作者，必填 |
| `isbn` | string | ISBN，可为空；手动录入时不允许重复 |
| `category` | string | 分类，必填 |
| `publisher` | string | 出版社，可为空 |
| `year` | number \| null | 出版年份，可为空 |
| `price` | number \| null | 单价（元），可为空 |
| `stock` | number | 库存册数，非负整数，最大 `99999` |
| `location` | string | 存放位置，可为空 |
| `notes` | string | 备注，最多 400 字 |
| `createdAt` | string | 创建时间，ISO 8601 格式 |
| `updatedAt` | string | 最后修改时间，ISO 8601 格式 |

## 自定义

所有代码都在 `index.html` 中，修改后刷新页面即可生效。

- **主题配色**：修改 `<style>` 顶部 `:root` 中的 `--forest`、`--terracotta`、`--gold`、`--paper` 等变量。
- **库存预警阈值**：修改脚本中的 `const LOW_STOCK = 2;`。注意页面提示文案中的“≤ 2 册”也需要同步修改。
- **本地存储键名**：修改 `const STORAGE_KEY = "moxiang-library-v1";`。换一个新键名相当于开启一套全新的空书架。
- **默认分类**：修改 `DEFAULT_CATEGORIES` 数组，控制新增图书时下拉建议出现的分类。
- **示例数据**：修改 `createSeedBooks()` 中的 `seeds` 数组。仅在本地没有数据时才会载入。
- **封面颜色**：修改 `COVER_PALETTE` 数组，图书封面的首字颜色会根据书名哈希自动选取。

> 如果已经打开过页面，仅修改示例数据不会覆盖浏览器中已保存的旧数据。需要先清除 `moxiang-library-v1` 再刷新。

## 常见问题

**刷新后数据没了？**

可能使用了无痕模式、清理了浏览器数据，或浏览器禁用了本地存储。页面在存储失败时会给出提示。建议检查浏览器设置，并定期导出 JSON 备份。

**换电脑怎么迁移？**

在旧设备点击 **导出**，把 JSON 文件传到新设备，打开页面后点击 **导入** 即可。

**删除后有办法恢复吗？**

没有内置回收站。若之前导出过备份，可以通过导入恢复；否则无法撤销。

**为什么 ISBN 保存不了？**

ISBN 在手动录入时按“去除空格和连字符后”的值检查重复。如果与已有图书重复，请修改 ISBN 或先编辑原记录。导入的备份不做强制去重。

**导入提示失败？**

请确认文件是 `.json` 格式，且由本页面导出，或至少包含 `books` 数组（也支持直接是数组）。文件大小不能超过 5 MB。

**可以部署到 GitHub Pages 吗？**

可以。`index.html` 是完全静态的单文件，上传后即可访问。但 `file://` 打开和 `https://` 部署属于不同来源，两边的本地数据不会互通，请先导出再导入。

## 技术说明

- 原生 HTML + CSS + JavaScript，无框架、无构建步骤、无外部依赖。
- 使用 `localStorage` 持久化，`Intl.Collator` 进行中文排序，`Intl.NumberFormat` 格式化数字。
- 使用原生 `<dialog>` 管理弹窗，并处理焦点返回、遮罩层和 `Esc` 关闭。
- 所有用户输入通过 `textContent` 或 HTML 转义后再渲染，避免把书名、备注等内容当作 HTML 执行。
- 响应式断点：`860px` 切换为卡片列表，`600px` 优化手机端工具栏和表单布局。
- 页面在 `prefers-reduced-motion` 下会关闭大部分过渡动画。
